# UAC Information Technologies

This repository contains the source code for UAC Information Technologies' company website, hosted at [uacinfo.github.io](https://uacinfo.github.io).

## Overview

UAC Information Technologies provides innovative software solutions, mobile applications, and custom development services to help businesses thrive in the digital landscape.

## Technology Stack

- **Framework**: Next.js 13.4.4
- **UI Library**: React 18.2.0
- **Styling**: TailwindCSS 3.3.2
- **Animations**: AOS (Animate On Scroll)
- **Language**: TypeScript 5.0.4

## Development

### Prerequisites

- Node.js
- npm

### Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/uacinfo/uacinfo.github.io.git
   cd uacinfo.github.io
   ```

2. Install dependencies
   ```bash
   npm install
   ```

3. Start the development server
   ```bash
   npm run dev
   ```

4. Build for production
   ```bash
   npm run build
   ```

5. Start production server
   ```bash
   npm run start
   ```
